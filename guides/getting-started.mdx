Vanna is a credit layer on Solana. You lend into Vanna's pools, or open one **margin account** that holds many collaterals, borrow against it, and use that loan across Solana: spot swaps (Jupiter / Titan), perps (Phoenix), Kamino lending, Perena and delta-neutral vaults, and World.xyz prediction markets.

**Live app:** [test.solana.vanna.finance](https://test.solana.vanna.finance)

<ForkNotice />

## Three steps to start

<Steps>
  <Step title="Add the fork RPC to your wallet">
    Install [Backpack](https://backpack.app/download) and add the custom RPC `https://rpc-devnet.solana.vanna.finance` so it shows fork balances and signs against the fork. The purple strip at the top of the app has a **Copy** button and links to the [wallet setup guide](/guides/connect-wallet#add-the-vanna-rpc-to-your-wallet).
  </Step>
  <Step title="Connect">
    Open [test.solana.vanna.finance](https://test.solana.vanna.finance), click the wallet button at the top right and approve the connection.
  </Step>
  <Step title="Fund from the Faucet">
    Click **Faucet** in the header and **Fund All**. You get 1,000 of each token (10 of each xStock) instantly, with no wallet approval. See [Faucet](/guides/faucet).
  </Step>
</Steps>

## The app at a glance

The header groups the pages the way money flows:

| Group | Page | What you do there |
|---|---|---|
| | [Portfolio](/guides/portfolio) | Everything you hold, earn and owe in one place |
| **Lend** | [Earn](/guides/earn/overview) | Supply SOL, USDC or USDT to Vanna's pools and earn borrow interest |
| **Lend** | [Predict](/guides/predict/overview) | Buy Yes / No on real World.xyz events; your shares earn in Vanna's USDC pool while you wait |
| **Borrow & Trade** | [Margin](/guides/margin/overview) | Deposit collateral, borrow up to 10×, repay, move collateral |
| **Borrow & Trade** | [Trade → Spot](/guides/trade/spot-swap) | Swap inside your margin account (Jupiter or Titan route) |
| **Borrow & Trade** | [Trade → Perps](/guides/perps/overview) | Long or short SOL, ETH, BTC, TSLA, META on Phoenix |
| **Borrow & Trade** | [Farm](/guides/farm/overview) | Put margin balances into Kamino, Perena or delta-neutral basis vaults |
| | [Analytics](/guides/analytics) | Protocol-wide risk, pools, collateral and prices |
| | [Copilot](/guides/copilot) | Ask about your account or describe a change in plain English |
| | [Vanna MCP](/guides/mcp) | Use Vanna from Claude, Cursor or any MCP-compatible AI assistant |
| | [Faucet](/guides/faucet) | Top up test tokens on the fork |

## Supported assets

| Asset | What it is | Lend (Earn) | Borrow | Margin collateral |
|---|---|:---:|:---:|:---:|
| SOL | Native SOL (wrapped to wSOL in vaults) | ✓ | ✓ | ✓ |
| USDC | Circle USDC | ✓ | ✓ | ✓ |
| USDT | Tether USD | ✓ | ✓ | Held, not offered as a deposit |
| JitoSOL, JupSOL | Liquid-staked SOL | | | ✓ |
| JupUSD | Jupiter USD | | | ✓ |
| NVDAx, GOOGLx, AAPLx, TSLAx | Backed Finance xStocks (tokenized equities, Token-2022) | | | ✓ |
| CASH | World.xyz's settlement token, used on Predict | | | |

Vault receipts you receive from Farm (kSOL, kUSDC, USD\*, vbSOL…) stay in your margin account and count as collateral too.

<Tip>
A wallet signature is not the final result. Wait for the confirmation toast and refreshed balances before the next step that depends on it.
</Tip>

## Read the card

| Field | Meaning |
|---|---|
| Collateral | Stock (or remaining equity) backing the account |
| Debt | Vanna borrow, including interest |
| Supplied to Kamino | Receipt value at the current reserve exchange rate |
| Net value | Supplied − debt, in the UI's unit |
| Net APR | Supply APR − borrow APR at current rates |

## Exit

1. Open **Position**.
2. Choose 25% / 50% / 75% / 100%.
3. Review estimated Kamino redeem, swap, and repay.
4. Confirm. `lite_reduce_*` / `lite_reduce_and_repay` unwind only **that** stock.

A 100% exit should repay that stock's debt and return leftover tokens to the margin vault (then withdrawable if health allows). Residual dust can remain after fees and slippage. Check the account before opening the next trade.

History is a separate tab. It does not by itself repay anything.

## How it works

Faucet top-ups use Surfpool **fork cheatcodes**: the server writes the new balance straight into fork state. There is no transaction to sign and no wallet approval. Nothing real moves; these tokens exist only on the fork.

- Keep some SOL in your wallet for transaction fees.
- CASH is the token World.xyz markets settle in. You only need it for [Predict](/guides/predict/overview).
- If a balance doesn't appear, check your wallet is pointed at the [fork RPC](/guides/connect-wallet#add-the-vanna-rpc-to-your-wallet) and wait a few seconds for the app to refresh.
